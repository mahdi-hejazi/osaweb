درخواست پروژه مشاهدهٔ کارها

دربارهٔ اوسا وب

من سیدمهدی حجازی هستم؛ توسعه‌دهندهٔ بک‌اند و فرانت‌اند. محصول را از نیاز اولیه تا رابط، API و انتشار در یک مسیر مشخص جلو می‌برم.

«اوسا» یعنی استادکار. اوسا وب همین معنا را برای توسعهٔ وب گرفته است: مسئله را مشخص می‌کنم، معماری مناسب را انتخاب می‌کنم، و تا استقرار و پشتیبانی کنار پروژه می‌مانم.

فروشگاه و پنل اختصاصی، سامانهٔ مالی، پلتفرم آموزشی، ربات پیام‌رسان، یا فروشگاه ووکامرس با کد اختصاصی — هر کدام با فناوری مناسب همان کار پیش می‌رود.

خدمات

هر خدمت از نیاز همان کسب‌وکار طراحی می‌شود و تا استقرار همراهی می‌شود.

۰۱

طراحی وب‌سایت و وب‌اپلیکیشن اختصاصی

سایت یا وب‌اپ برای فرایند همان کسب‌وکار طراحی می‌شود. رابط، منطق و استقرار در یک مسیر است و نتیجه روی موبایل و دسکتاپ قابل استفاده می‌ماند.

۰۲

طراحی مارکت‌پلیس

چند فروشنده، کاتالوگ، سفارش و تسویه در یک محصول. نقش هر طرف و مسیر خرید از اول مشخص می‌شود و هر فروشنده پنل خودش را دارد.

۰۳

پنل مدیریت

محصول، سفارش، کاربر، نقش و گزارش از یک پنل جدا اداره می‌شود. هر نفر فقط بخش لازم کارش را می‌بیند و کار روزانه به تغییر کد وابسته نمی‌ماند.

۰۴

فروشگاه اینترنتی

کاتالوگ، جستجو، سبد، پرداخت و پیگیری سفارش. برای فهرست بزرگ، کش، صف و search engine هم جزو طراحی فروشگاه است.

۰۵

وردپرس و کد اختصاصی

راه‌اندازی فروشگاه ووکامرس، و نوشتن قطعه کد یا افزونه جایی که منطق فروش در ابزار آماده نیست. از سبد و حمل تا فاکتور و آمار بازدید.

۰۶

اتصال و اتوماسیون

ربات تلگرام و بله، انتقال کاتالوگ یا خواندن قیمت، و اتصال سایت به هوش مصنوعی تا کار تکراری از جریان روزانه خارج شود.

تخصص‌ها

ستون‌های اصلی کار، و ابزارهایی که محصول را به عملیات روزمره وصل می‌کنند.

۰۱

لاراول و پی‌اچ‌پی Laravel · PHP

بک‌اند امن و مقیاس‌پذیر با لاراول — از سامانه‌های سازمانی تا فروشگاه و سرویس‌های API، با معماری تمیز و قابل توسعه.

  • طراحی معماری MVC، مدل‌های Eloquent و روابط دیتابیس
  • احراز هویت، نقش و دسترسی، امنیت و اعتبارسنجی درخواست‌ها
  • رابط یکپارچه با Inertia و پنل تعاملی با Livewire
  • API از نوع RESTful با نسخه‌بندی، Resource و مستندسازی برای فرانت‌اند و موبایل
  • API از نوع GraphQL برای دریافت دقیق داده‌های موردنیاز و کاهش رفت‌وبرگشت‌های اضافه
  • صف‌ها، جاب‌ها، اعلان‌ها و کارهای زمان‌بندی‌شده
  • بهینه‌سازی کوئری، کش و استقرار روی سرور لینوکس
  • پی‌اچ‌پی برای منطق سرور، از لاراول تا کد و افزونهٔ اختصاصی ووکامرس
۰۲

ویو جی‌اس و ناکس Vue.js · Nuxt

رابط کاربری با ویو جی‌اس، و ویترین سمت‌سرور با ناکس — برای داشبورد، فرم پیچیده و فروشگاهی که هم سریع باشد و هم برای سئو قابل خواندن.

  • ساخت کامپوننت‌های قابل استفاده مجدد با Vue 3 و Composition API
  • مدیریت state، مسیریابی و ارتباط با API
  • فرم‌های تعاملی، اعتبارسنجی سمت کلاینت و بازخورد لحظه‌ای
  • داشبورد مدیریت، پنل کاربری و صفحات تک‌صفحه‌ای (SPA)
  • هماهنگی کامل با لاراول، از بک‌اند تا فرانت‌اند
  • ناکس برای رندر سمت سرور، رابط راست‌چین و صفحهٔ قابل ایندکس
۰۳

وردپرس WordPress

از راه‌اندازی فروشگاه ووکامرس تا قالب، افزونه و قطعه کد اختصاصی — جایی که منطق فروش در افزونهٔ آماده نیست، همان منطق را می‌نویسم.

نصب و راه‌اندازی

  • امن‌سازی اولیه، پشتیبان‌گیری و به‌روزرسانی اصولی
  • راه‌اندازی فروشگاه ووکامرس و افزونه‌های ضروری
  • بهینه‌سازی سرعت، کش و سئوی پایه

قالب و افزونهٔ اختصاصی

  • طراحی و کدنویسی قالب سفارشی مطابق برند شما
  • توسعهٔ افزونه با منطق کسب‌وکار اختصاصی
  • سفارشی‌سازی تم‌های موجود و Child Theme
  • اتصال به درگاه پرداخت، پیامک و سرویس‌های خارجی

ابزارقطعه فروشگاه اینترنتی ابزار برقی و قطعات یدکی است و سفارش را به سراسر ایران می‌فرستد. محدودهٔ کار، طراحی فروشگاه برای مشتری و پنل برای عملیات روزانهٔ فروش بود. هر دو روی یک API با لاراول کار می‌کنند.

فروشگاه سمت سرور رندر می‌شود، راست‌چین است و روی موبایل و دسکتاپ درست کار می‌کند. حالت روشن و تیره هم دارد. برای سرعت کاتالوگ بزرگ، کش و صف با Redis است و جستجو با search engine انجام می‌شود. سفارش قطعه یدکی از روی نقشه دستگاه، جدا از خرید معمولی کالا، داخل همان سفارش بررسی و قیمت‌گذاری می‌شود.

نسخه قبلی با وردپرس بود و به این سیستم منتقل شد. آدرس‌های قدیمی به آدرس جدید هدایت می‌شوند.
